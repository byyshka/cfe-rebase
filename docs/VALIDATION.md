## Как повторить

```
cfe-rebase control-rebase --ext <расширения> --old <old> --new <new> --out <папка> [--work <эталон>]
cfe-rebase method-diff    --ext <расширения> --old <old> --new <new> --out <папка>
cfe-rebase interceptors   --ext-root <расширения> --config-old <old> --config-new <new> --out <папка>
cfe-rebase borrowed       --ext-root <расширения> --config-old <old> --config-new <new> --out <папка>
cfe-rebase registers      --ext-root <расширения> --config-old <old> --config-new <new> --out <папка>
cfe-rebase reads          --ext-root <расширения> --config-old <old> --config-new <new> --out <папка>
cfe-rebase lint           --work <рабочая копия> --ext <расширения> --out <папка>
cfe-rebase prepare        --db <база> --to <релиз> --no-dump      # семь отчётов и план
```

Сравнение двух прогонов — `git diff --no-index` по `report.json` (путей и времени в нём нет, если аргументы те же)
и по каталогам кандидатов; работает и на Windows без Unix-утилит. Для прогонов с разными корнями — нормализатор `tests/corpus/normalize.py`.
